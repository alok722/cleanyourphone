# realme narzo 20 (RMX2193), Android 11, realme UI 2.0, build RMX2191_11_C.19, security patch 2022-09-05
# Tested by @alok722 on 11 Nov 2026 with `cmp go`: the seven groups below disabled in ten checked batches
# (compass kept), restarted, home screen, keyboard, phone, Play Store and proximity sensor fine afterwards.
# About 45% more free RAM afterwards. Used the same day only, not yet for days.
#
# Apply:  ./cmp go   (or ./cmp apply devices/realme-narzo-20-rmx2193/debloat.txt)
# Undo:   ./cmp restore
# Comment out any line you want to keep.
#
# realme UI 2.0 quirks on this build:
# - `settings put` is refused unless Developer options > "Disable permission monitoring" is on (it resets at
#   reboot). cmp taps through Developer options instead; this build calls one row "Transition animation zoom".
#   Private DNS (ad blocking) has no tap-through yet, so it is set by hand.
# - Every package here disabled normally; unlike the realme 7, Theme Store did not need suspend.
# - The phone app is Google's, so realme codes like *#899# give "invalid MMI code". MediaTek's
#   *#*#3646633#*#* works while its engineer mode is enabled, but has no sensor screens on this build.
# - Apps you installed yourself and uninstall with `cmp go` come back from the Play Store, not `cmp restore`.
