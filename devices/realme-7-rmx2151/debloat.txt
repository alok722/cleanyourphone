# realme 7 (RMX2151), Android 12, realme UI 3.0, build RMX2151_11_F.12, security patch 2022-11-05
# Tested by @alok722 on 30 Oct 2026: phone used daily afterwards, calls, SMS, VoLTE (Jio/Airtel), camera,
# Play Store, WhatsApp, banking apps all fine. About 60% more free RAM afterwards.
#
# Apply:  ./cmp apply devices/realme-7-rmx2151/debloat.txt
# Undo:   ./cmp restore
# Comment out any line you want to keep.
#
# ColorOS quirks on this build:
# - com.heytap.market and com.heytap.themestore refuse disable-user and uninstall; cmp falls back to suspend.
# - Suspending Theme Store breaks the "Recent" tab in Settings > Wallpapers and theme changes.
# - `settings put` is refused unless Developer options > "Disable permission monitoring" is on (it resets
#   at reboot); cmp tune falls back to tapping through Settings.
