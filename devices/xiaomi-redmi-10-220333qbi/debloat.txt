# Xiaomi Redmi 10 (220333QBI, "fog", India), Android 13, MIUI 14.0.7 (V14.0.7.0.TGEINXM), security patch 2024-09-01
# Tested by @alok722 on 31 Oct 2026 with `cmp go`: all five groups below disabled in five checked batches,
# home screen, keyboard, phone, messages and Play Store fine afterwards.
#
# Apply:  ./cmp go   (or ./cmp apply devices/xiaomi-redmi-10-220333qbi/debloat.txt)
# Undo:   ./cmp restore
# Comment out any line you want to keep.
#
# MIUI quirks on this build:
# - After a restart MIUI can take minutes to reappear over USB; cmp waits up to 7 minutes and resumes with `./cmp go`.
# - `settings put` (animations, refresh rate, Private DNS) is refused over adb unless Developer options >
#   "USB debugging (Security settings)" is on, which MIUI only allows with a SIM and a Mi account. Without it,
#   set those by hand; cmp lists them as notes in DONE.
# - MIUI blocks uninstalling its own apps (Weather: Failure [-1000]); cmp disables those instead.
